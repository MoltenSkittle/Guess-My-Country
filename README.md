# Guess-My-Country
Guess My Country is a hangman-styled game where players can go against bots of varying difficulty in attempt to guess each other's countries, one letter at a time, in order to win.

How I Built It: I originally created a solver for a game similar to this one, which I will release shortly. The solver's code was adapted to some of the bots to create really the engines that allow the hardest ones to always win in four guesses or under.

How To Play: Choose a difficulty (1 = Easiest, 5 = Hardest). Them, choose a country out of the 195 UN members and 2 observer states. Afterwards, the game is introduced. You will be given an outline of the bot's hidden country, and every time it's your turn, you will have the opportunity to either guess a letter (and reveal all instances of that letter in the bot's country), or guess the bot's entire country. Note that guessing the bot's country incorrectly results in a loss!

How To Run: At https://github.com/MoltenSkittle/Guess-My-Country/releases/tag/v1.0, download BOTH the gmcdict_v1.0.json file and the gmc_v0.4.exe file. Afterwards, execute the gmc_v0.4.exe file, and your game will begin!
