# Guess-My-Country
Guess My Country is a hangman-styled game where players can go against bots of varying difficulty in attempt to guess each other's countries, one letter at a time, in order to win.

# How I Built It: 
I originally created a solver for a game that inspired this one. The solver's code was adapted to some of the bots to create the engines that allow the hardest ones to always win in four guesses or under.

# How To Play: 
Choose a difficulty from easiest to near-impossible, then choose a country. There are 196 countries to choose from. Every turn, you will have the opportunity to guess a single letter. If your letter ends up being in the bot's country, it will reveal all instances of that letter in their country. There is no penalty for incorrectly guessing a letter other than letting the bot catch up. Alternatively, you can try guessing your bot's entire country to win immediately. Note that guessing incorrectly here will cost you the entire match!

You can choose between five difficulties, ranging from easy to near-impossible. Additionally, there are various game modes that can be chosen from, which can restrict the countries to a particular continent.

# How To Run: 
At https://github.com/MoltenSkittle/Guess-My-Country/releases/tag/v1.2, make sure to download the **.exe file**, the **.json file**, and the **three .png files**. Afterwards, run the .exe file, and the game will start up!
